# IA da CPU (parcial)
0x15B90: a CPU passa ao acaso para a ação 0x12 (C). Atordoamento: 0x16D92, 0x1CCE8 e 0x1CD50 (C, segundo as notas). As demais rotinas de 0x15xxx/0x1Cxxx estão pendentes.
Árbitro (objeto 1C0AB2), som (0x25E6 com 101 chamadores; o driver Z80 não foi analisado) e pin/contagem: PENDENTES.
